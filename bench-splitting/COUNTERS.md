# PMU counter statistics (Zen 4 measurement campaign, 2026-07-02/03)

Normalized counter tables for every experiment in PERF.md's RESULTS
sections, generated by perf_analyze.jl from the raw perf-stat windows
(raw dumps kept out of the repo; regenerate any experiment with
perf_matrix.sh — it records the exact Zen 4 event groups).

Machine: AMD EPYC 9354 (Zen 4), ~3.2 GHz, 32K L1i / 1M L2 / 32M L3/CCX.
All values are per benchmark iteration (events/sec divided by iters/sec;
PERFDONE-based). Event mapping from the ADL originals: see PERF.md.

Caveats: off baselines vary +-10-20% across processes (code layout);
compare split-vs-off within one experiment, not across builds.
